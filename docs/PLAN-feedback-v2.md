# 用户首测反馈修复规划 v2

日期2026-10-28；基线d979940。授权依据：用户本轮要求修复截图延迟/闪屏、加入画笔与文字标注、修复截图后识图不可用、排查三至五分钟录音截断和长输入失败；此前已授权Luna实施/干净Luna审查/自动测试/Computer Use/提交/本地交付。本规划落实本轮新增范围，历史v1文档及审查不修改。

## 目标与交互

1. 截图采用后台预热的常驻Windows捕获进程，触发时才抓屏，不后台持续保存屏幕。减少重复进程启动；冻结图解码绘制就绪再显示框选窗，避免黑屏闪一下。记录旧版与修复版触发至可框选耗时；同环境预热截图目标低于1秒，首发冷启动单独报告。
2. 框选松开进入编辑预览，提供画笔、文字、撤销、完成、取消；完成/Enter后将带标注PNG复制，Esc或取消零剪贴板写入。保持原分辨率，笔画/文字坐标映射到输出像素，跨屏源匹配/DPI及安全校验保留。本项取代v1松开立即复制交互。
3. 保留逐模型显式多模态开关；不按模型名静默推断。识图禁用时显示原因，截图后直接反馈所缺条件，提供设置入口；当前真实模型未勾选的问题通过原有设置修正并备份配置，仅开启已验证当前provider的multimodal，不改其他配置。实测真实截图→按钮启用、外部图→识图→文字剪贴板、能力关闭→原因可见，结果仍只复制不自动粘贴。
4. 长录音不使用易受主线程影响的ScriptProcessor单独作为唯一采集通路：使用AudioWorklet连续采集，保留兼容回退；设置backgroundThrottling:false，停止时排空尾帧，准确构造16k单声道PCM WAV。采集器异常/中断不无声当成功；保留已采集内容供恢复。
5. WAV按连续样本分段识别，单段不超过30秒，段边界尽量在静音附近，音频样本完整覆盖、无重复跳过；严格按序合并，不用模糊文本去重删除有效话语。保留短音频及两种ASR协议兼容。每段有界超时；拒绝finish_reason=length/content_filter等不完整响应；失败不能将前几段当完整成功交付。
6. 转录/后续文字整理失败时保留本地临时恢复录音或已转写原文，提供明确错误与重新转录/恢复入口，防止长输入直接丢失；恢复不默认自动粘贴，退出不产生迟到发布。敏感音频/全文恢复数据不进Git，明确清理/替换策略。

## 实施与验收边界

U1 捕获速度/绘制就绪；U2 标注编辑；U3 识图原因和配置联动；U4 长录音采集/分段/恢复。互不重叠文件可分配Luna并行，接口由主代理协调。每单元做有意义的确定性测试；整合候选提交后由未参与实施、fork none的干净Luna全范围审查，失败保留并修复后换新审查人。主代理负责实机总检查、构建及主目录本地提交交付。

验收：B01暖截图耗时与无未绘制窗；B02画笔/文字/撤销/完成像素，取消不写；B03真实配置缺能力可见，设置后截图识图跑通；B04三/五分钟PCM首中尾采样完整、后台与停止尾帧；B05每段<=30秒且完整覆盖，合并顺序正确，两协议与截断/超时/429/中段失败；B06失败后可恢复/重试不误粘贴，不以部分成功冒充完整；B07原有热键/录音/文字/Undo/剪贴板互斥回归；B08本地便携包运行和资源验证。

## 证据与访问

已有v1八次视觉调用预算和证据不变；新周期最多12次真实调用（最多10次ASR，最多2次视觉），只发送已冻结的已知文字合成语音/图片，不发送用户录音/桌面。调用前冻结夹具、请求适配/提示词哈希及预算计数；无自动重置或无限重试。数据/凭据门禁失败则零调用/不解密密钥。其余测试均本地mock/临时profile。真实用户配置只读取必要元数据，模型密钥不打印/落盘；开启当前provider多模态前保留本地配置备份。仅本地提交及便携包，不推送/对外发布。

依据：小米ASR官方模型列表8k上下文/2k输出；音频文档Base64<=10MB，API finish_reason=length表示达到长度限制。https://mimo.mi.com/docs/zh-CN/quick-start/summary/model ; https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/Speech-Recognition ; https://mimo.mi.com/docs/en-US/api/audio/Speech-Recognition 。不把这些限制当作尚未复现的前30秒缺失的唯一原因。
