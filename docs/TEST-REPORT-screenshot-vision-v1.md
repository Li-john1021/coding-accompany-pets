## 环境与证据边界

- Windows 11 家庭中文版 10.0.22631，Electron 31.7.7，Windows x64。
- P3 主屏 2560×1440 / 100%，副屏物理 1920×1080 / 125%，位于右侧；最终便携版测试时只连接主屏。负原点有像素夹具验证，未连接物理负坐标屏幕。

- 仅授权的八次请求读取配置凭据，未输出/存储凭据值，未修改真实用户配置。其他集成使用临时配置、空/假密钥和 localhost 服务。
- 原始失败及修复审查均保留；P1–P5 独立 Luna 审查通过，最终候选另交全范围独立审查，见 docs/audits。
