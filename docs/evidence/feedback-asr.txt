Scope: deterministic local tests only. No user profile, credentials, microphone, or provider API calls.

Implementation notes:
- Renderer capture prefers AudioWorklet `v2p-pcm-capture`; the ScriptProcessor path remains as a compatibility fallback.
- Worklet transfers captured PCM blocks to the renderer and responds to an explicit stop flush before audio context shutdown.
- Main process splits validated mono PCM16 WAV samples into contiguous chunks no longer than 30 seconds. Boundaries search nearby low-energy windows and do not omit or duplicate samples.
- ASR calls are sequential and bounded per chunk; any failed chunk rejects the full transcription. Chat completion `length` and `content_filter` finish reasons are rejected.
- Pipeline saves the source WAV to the configured recovery directory before ASR. Recovery is retained on failure and removed after successful full processing. Recovery APIs support WAV and raw transcript retention.
- The renderer's recovery action requires a click and retries transcription; it does not automatically paste recovered data.
