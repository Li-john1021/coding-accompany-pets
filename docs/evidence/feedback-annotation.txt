U2 annotation implementation evidence
Status: implementation complete; focused unit/syntax checks pass
Interaction: selector mouseup composes the crop into a local preview editor. Pen and text annotations are rendered in output-image coordinates; undo removes the latest annotation. Done or Enter sends one final PNG to the existing main-process validator. Escape or Cancel sends cancellation and never calls composed(), so the clipboard write path is unreachable.
Privacy: captured image data remains in memory in the renderer. No disk writes, network calls, or provider calls are part of this flow.
Unit checks: `node app/renderer/screenshot-annotation.unit.test.js`, `node app/main/screenshot-controller.unit.test.js`, and `node app/main/screenshot-geometry.unit.test.js` pass. `node --check` passes for controller, preload, renderer, annotation module, and production runtime test.
Production runtime regression was extended to cover exact crop dimensions, pen/text and undo pixels, delayed clipboard write until Done, byte-for-byte clipboard preservation when canceling the editor, and mixed-DPI cross-screen completion. Two attempts to launch it failed before the fixture started: Electron loaded the configured app `main.js` (`[mouse] hook on`), then the wrapper failed because it received no `SCREENSHOT_P3` result. No Electron process remains. Parent has been notified to include the runtime regression in integrated native validation.
